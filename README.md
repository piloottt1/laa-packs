# LAA Packs

Сборки LAA для игры с друзьями. Выбирай сборку в **LAA Launcher**, нажимай «Играть» и отправляйся в игру.

**LAA Launcher** — портативный лаунчер: его достаточно скачать и распаковать. Он сам загрузит выбранную сборку, подготовит Java и проверит обновления. Можно играть по нику или войти через Ely.by.

[Скачать лаунчер и посмотреть сборки](https://github.com/piloottt1/laa-packs/releases)
