# LAA Packs

Публичный каталог сборок для LAA Launcher. В `catalog.json` указаны версии лаунчера и сборок, ссылки на архивы GitHub Releases и контрольные суммы SHA-256.

Новая сборка публикуется так: создать ZIP экземпляра PineconeMC с `mmc-pack.json` и `instance.cfg` в корне архива, загрузить его в отдельный Release, затем добавить или обновить запись в `catalog.json`. Перед изменением каталога вычислить SHA-256 готового ZIP. Личные данные игроков, сохранения и карты в релизы не добавлять.

Исходники лаунчера хранятся отдельно. Этот репозиторий публичный и содержит только каталог и выпуски.
