# LAA Packs

Публичный каталог сборок для LAA Launcher. В `catalog.json` указаны версии лаунчера и сборок, ссылки на ZIP в GitHub Releases, размеры, SHA-256 и Java для каждой сборки (`java: 8` или `java: 25`).

Для новой сборки создайте ZIP экземпляра PineconeMC с `mmc-pack.json` и `instance.cfg` в корне, загрузите его в отдельный Release и добавьте запись в `catalog.json` с уникальными `id` и `instanceId`. Перед публикацией вычислите SHA-256 готового ZIP. Личные данные игроков, сохранения и карты в релизы не добавляйте.

Лаунчер и установленные сборки обновляются отдельно. Исходники лаунчера хранятся в отдельном приватном репозитории.
